.. _requested_procedure:

Requested Procedure
===================

A Requested Procedure can contain Scheduled Procedure Steps (0040,0100) of different modalities. It is therefore NOT modality-specific.

It is important to differentiate between Requested Procedure Description (0032,1060), which is used in the Modality Worklist to describe what images SHALL be taken, and Reason For Visit (0032,1066/0032,1067), which reflects the appointment or procedure type from the scheduling system, used in the IOD. For details on Reason For Visit, see :ref:`reason_for_visit`.

.. _RequestedProcedureComments:

Requested Procedure Comments (0040,1040)
----------------------------------------

- This attribute MAY be used to provide additional comments or instructions related to the requested procedure.
- Examples include a related field from the PMS, patient-specific notes, or clarifications for the imaging staff.

.. _RequestedProcedureDescription:

Requested Procedure Description (0032,1060)
--------------------------------------------

- (0032,1060) SHALL be used in the Modality Worklist to describe what kind of images should be taken. Examples include "simple extra-oral photographs", "Initial records", or other descriptions that define the imaging requirements for the appointment.
- This MAY be derived from the appointment type in the PMS, but SHOULD reflect the actual images to be acquired during the appointment.
- If the PMS only provides free text for the reason for the appointment, then usage of (0032,1060) alone SHALL be allowed.

.. _RequestedProcedureCodeSequence:

Requested Procedure Code Sequence (0032,1064)
----------------------------------------------

- If the PMS uses values from a set, such as those used for billing, or a pre-programmed or customizable list, then (0032,1064) SHALL be used.
- In this case, (0032,1060) MAY be used with the Code Meaning from this sequence.
- Multiple items MAY be included in this sequence, provided they describe the same procedure from different coding systems.

.. _RequestedProcedureID:

Requested Procedure ID (0040,1001)
-----------------------------------

- This attribute SHALL be used to uniquely identify the requested procedure within the system.
- The value MAY be generated by the PMS or scheduling system and SHOULD be unique for each procedure request.
- Examples include appointment IDs, procedure request numbers, or other unique identifiers.
