3 Orthodontic Imaging (OIP) Profile
===================================

Orthodontic imaging today relies on a fragmented landscape of proprietary implementations. Imaging devices and software from different vendors store and label photographic images in incompatible ways, limiting image exchange across sites and interoperability with other clinical systems. The Orthodontic Imaging Profile (OIP) addresses this by specifying how orthodontic visible light photographs shall be encoded using DICOM and SNOMED CT, establishing a single, implementable standard for the orthodontic imaging community.

This version of OIP is scoped to the creation and display of Visible Light Photographic Images (VL Photographic Image IOD). Support for other DICOM IODs used in orthodontics is deferred to future revisions.
